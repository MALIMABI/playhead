# Playhead

Трекер времени для креативщиков. Сам считает время в рабочих программах — Premiere, DaVinci,
Lightroom, Figma, After Effects, Blender и других — и раскладывает его по этапам и проектам.
Видео, фото, дизайн, моушн, звук, 3D-печать. Mac и Windows.

## Установка на Мак

1. Открой `.dmg` и перетащи Playhead в «Программы».
2. Запусти. Если macOS скажет, что не может проверить разработчика:
   Настройки → Конфиденциальность и безопасность → «Всё равно открыть».
3. Дальше Playhead обновляется сам — в окне появится «Доступна версия → Обновить».
